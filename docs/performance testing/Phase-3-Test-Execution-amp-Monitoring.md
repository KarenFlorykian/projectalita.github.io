# Phase 3: Test Execution &amp; Monitoring

**Owner:**  Performance Test Lead

**ENTRY CRITERIA**: Scripts validated and test environment ready

### Execute performance tests and Define Baseline

**Personal Work | Execution Orchestrator**

- Deploy test scripts to execution agent
- Initiate load tests according to test plan
- Validate performance KPI metrics
- Analyse error logs and stack traces
- Flag anomalies or failures during execution
- Consolidate performance metrics
- Set Baseline and Thresholds

### Correlate test results with monitoring metrics

**Personal Work |  Monitoring MCP** 

- Consolidate logs and system level monitoring metric
- Get raw data reports for analysis
- Analyse test results metrics patterns across monitoring MCP
- Highlight list of findings

### Validate findings with anomaly detection

**Personal Work | Anomaly Detection**

- Apply statistical analysis to identify anomaly category
- Validate detected issues against monitoring metrics
- Filter false positives from real issues
- Consolidate list of findings
- Report findings and track resolution
