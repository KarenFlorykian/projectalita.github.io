# Phase 4: Performance Analysis

**Owner:** Performance Analyst &#x2F; Delivery Team<br>**ENTRY CRITERIA:** Test execution complete with collected results

### Perform root cause analysis in collaboration with Delivery Team

**In a meeting | Transaction Breakdown Builder** 

- Review threshold breaches
- Run investigative  tests for isolated failed journeys
- Generate Transaction Breakdown for failed transactions
- Create reusable analysis templates \(RCA template\)
- Review findings with delivery team findings  

### Validate and retest after fixes 

**Personal Work | Execution Orchestrator**

- Coordinate with delivery team on fixes   
- Rerun targeted tests after remediation   
- Verify performance improvements meet thresholds  
- Update test results with validation outcomes

### Capture learnings in knowledge base

**In a Meeting | Collaborative Work**

- Review findings with delivery team findings  
- Document root causes and resolutions
- Update RCA template 

### Adjust baselines and thresholds based on changes

**Execution Orchestrator| Baseline Curator**

- Review alerts from Thresholds, Baseline Breaches 
- Adjust Baseline with latest changes
- Update Thresholds if justified 
- Document Thresholds adjustment
