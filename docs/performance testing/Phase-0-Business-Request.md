# Phase 0: Business Request

**Owner:** Product Owner

### Recognise performance testing need for application or service

**In a Meeting \(Owner aka Sergey\) | Manual Process**

- Identify motivation behind performance testing initiative
- Obtain knowledge about business and system under test 
- What testing components required: Backend, Web UI, Mobile UI
- Obtain knowledge existing performance testing process

### Define preliminary scope and performance expectations

**Personal Work | Manual Process**

- Document brief system overview and business context
- Outline scope and usage scenarios \(peak load\)
- Establish expected business value and success criteria

### Submit performance testing request to delivery team

**Context Acquisition | Personal Work \(*Agent to ask questions, estimate complexity, get high\-level scope\)***

- Prepare initial business case with scope
- Share performance topics and existing test information
- Request discovery approach and next steps

**Checkpoint:** Request accepted and assigned to performance team
